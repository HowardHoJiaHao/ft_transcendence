# Demo upload asset

Use `yonex-racket-specification.md` as the source content for a PDF attachment.

For the demo, open it in a Markdown viewer or browser and choose **Print → Save as PDF**.
Name the exported file `yonex-astrox-88d-specification.pdf`.

The sample is fictional and contains no real receipt or personal information.

## Ready-to-upload PDF

Use `demo-racket-receipt-specification.pdf` for the file-management demo. It is
a one-page A4 document containing a fictional receipt, racket specifications,
and a clear demonstration-only notice.

`demo-racket-receipt-specification.html` is the editable source for that PDF.
